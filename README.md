# Minecraft Boss Battle Plugin

BossBattleMode is a Minecraft Paper plugin that adds a Wither boss battle with a custom boss bar, live health tracking, and commands to spawn or remove the boss.

## Install

1. Build the project with Java 21 and Maven by running `mvn package`.
2. Copy `target/plugin.jar` into your Paper server's `plugins` folder.
3. Restart the server.

## Use

1. As a player with the `bossbarboss.admin` permission, run `/boss spawn` to summon the Abyssal Boss in your world.
2. Fight the Wither. Players in its world see a boss bar that updates with its health.
3. Run `/boss remove` to remove the active boss.
